## Unified inference contract

The **semantic Prompt artifact** is exactly the stored `definitions` text; the classifier wrapper and native HF chat serialization are properties of the origin/deployment model. To retain source-to-target fidelity, Llama and Granite use their frozen Appendix-F classifier wrapper, whereas Qwen uses the frozen `package_minimal` classifier wrapper used to optimize its source Prompt. A literally identical outer sentence across all models would silently change Qwen's source–target interface and invalidate the origin-matched comparison. This model-specific wording is fixed before this RQ1 run; all `p0` and `p*` within each model share it. Comparisons of *absolute* scores between models remain confounded by wrapper and should not be called pure model effects.

All three models otherwise share one output/runtime policy: original pinned local HF weights, local canonical tokenizer/chat template, vLLM 0.6.4 on V100, FP16, temperature 0, top-p 1, top-k −1, engine seed 0, max model length 8,192, classification context cap 2,048, generation cap 64, dispatch batch size 1. Labels and guided binary choice are exactly `["Non-security", "Security"]` through `lm-format-enforcer`. Use three logical votes per item and majority for **both** `p0` and `p*` on each origin model. Store each raw/parsed vote, rendered-request hash, model fingerprint, prompt hash and item ID. Any invalid, empty, truncated, or errored response fails the affected job; never fabricate a third class or coerce a bad response to a label. No target-side examples or labels enter the model input.

The old 3×5 preflight produced 612/612 valid binary answers and perfect three-repeat agreement for each active model on 204 SecReq seed-42 source-test items. It was a source-only interface check, **not an accuracy-based model selection step**. Recheck artifact hashes and template fingerprints at RQ1 start.
